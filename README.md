# DomiSoins - Plateforme de Soins et Santé à Domicile (Berkane)

Plateforme complète de réservation de soins infirmiers, visites médicales à domicile, gestion des professionnels de santé et administration médicale avec comptabilité en temps réel.

---

## 🚀 Démarrage Rapide en Local

### 1. Installation des dépendances
Ouvrez votre terminal dans le dossier du projet :
```bash
npm install
```

---

### 2. Lancer en Mode Développement (Recommandé)
Pour lancer le serveur de développement avec rechargement automatique :
```bash
npm run dev
```
> **Note :** La commande est bien `npm run dev` (et non `npm start dev`).

L'application sera accessible sur : **`http://localhost:3000`**

---

### 3. Lancer en Mode Production
Si vous souhaitez compiler et exécuter la version de production :
```bash
# 1. Compiler le frontend et le backend
npm run build

# 2. Démarrer le serveur de production
npm start
```
